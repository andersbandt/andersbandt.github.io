About Me

My name is Anders, an engineer working on embedded systems. I graduated from University of Wisconsin-Madison studying Electrical Engineering and Mathematics.

I've always had a passion for making things, working at aMakerspace in college. I really enjoy all aspects of making, everything from 3D printing to woodworking to electronics work. Recently, I've started to focus on some ambitious electronics projects, mainly my wearable (no project page for this one yet)

I enjoy building things from scratch that I can use in my daily life. I've been working on documenting design decisions, so when I circle back to a project years later I can pick up right where I started. This blog is trying to practice that documentation aspect!

Some of my areas of interest include wearable technology, IoT devices, hydroponics and light/audio design.

I'm confortable with the following technologies / skills

  • PCB layout (Altium, KiCAD)
  • Embedded programming (mostly in C)
  • Hardware / software integration
  • Silicon validation

My other hobbies include running / exercise, cooking, and travel.
