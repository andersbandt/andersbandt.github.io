Probe testing for embedded devices

Introduction

Background

When I was working at Texas Instruments I got exposed to "probe testing", which involved using probe needles to make electrical contact with a semiconductor wafer for testing all the ICs on the wafer. This method of testing wafers has many advantages, including

  • getting access to certain signals that may be wire-bonded out in the final packaged device
  • very high pin-count possible

I wanted to take the same concept of probe testing and apply it to PCBs. Now, this is not new at all, in fact it's probably misleading to start this article talking about semiconductor test when these methods already exist for PCB testing. The term for PCB devices is often "bed of nails testing" or "ICT testing"

But because of my inspirations for working on [[Software controlled embedded test setup]] also stemming from working on semiconductor test equipment, I'll keep the theme of comparisons going with this article too :)

The main goal of this project is to create some mechanical/electrical fixture that can be mounted to a PCB board and make electrical contact at all the test points we want. The test PCB will then have some other connectors on it to connect to your test equipment or host PC. In this way, we have easy access to a large number of signals, and more important it can be done in a repeatable way. Our "probe tester" PCB can be connected to our bench electrical equipment, and these connections can remain constant. We can then swap PCBs easily and not have to go through the pain-staking (and error process) of re-hooking up all our test equipment. When you are deep in debug with multiple power rails being supplied, crazy grounding, maybe some extra external PCB, and 4 channels of oscilloscope probes these can add up.

Motivations

The main motivations for making this are

  1. My experience with probe testing on semiconductor devices and an appreciation for it
  2. My most recent personal embedded project with very small board size and not much room for large test points
  3. A need to easily PCBs under test

The last point was the most important, but as I work on v2 I'm Maybe one has a certain IC soldered one or I am trying different capacitor values on. This board enables me to quickly swap between designs and have all pins mapped the same way to whatever test equipment I have connected.

Requirements

Scope of work

This project is fairly simple, really it's more of a mechanical design problem than a complicated electrical schematic problem. The eventual PCB created has no actual electrical components, and is really in a sense a glorified connector.

Resources

Essentially all you will need to start this project is

  • ECAD software
    • I used Altium, my preferred, but KiCAD is a great, free open-source alternative
  • A PCB that you want to test
    • it's really best if this PCB has mounting holes for a nice mechanical connection as well
  • The coordinates of all your various test points on your PCB

Design

Initial Prototype

For proof of concept I 3D printed an early prototype that just had access to UART TX and RX lines.

This is version 1 of the 3D print. I had alignment issues that I tried to solve with hot-glue, but that proved not to be an elegant solution. Hot glue often has a habit of seeming like a solution, but it is almost always replaced by something else!

Version 2 of the 3D print prototype just added lots of upwards thickness. Pretty simple solution.

Design Approach

Off-board connector I knew that one function of this is board is that it would connect to another test board that would provide larger connectors such as banana jacks and more 2.54mm header pins on it. Thus, we would need a connector.

For connector type I really have grown to like typical IDC connectors. The cables for some length / pin combinations can be expensive, but the quality of these are already really good.

On-board test points I also wanted the probe PCB itself to have some test points. These can be useful for either testing my cable connection, or just simple 2.54mm header wires or probes for certain signal access. It's also kind of a requirement to include these as access to any of the original test points will be blocked.

Probes One thing to consider is the shape of the probe tip you select. Depending on your pad shape and type, this should be selected.

You can even have multiple probe tip types per design. For example, in my board all the through-hole "pads" I have that are actually for a 2.54mm header, are a different type than my standard circular pad.

Implementation and Building

Process

Really the PCB layout was quite simple.

I simple made a table of all the test points I wanted to include in my design and marked down the XY coordinates. For layout, I simply just went through all my probe footprints and put them at that exact XY coordinate.

Routing was so simple and could easily be done on a 2 layer board.

I ordered the boards from PCBway, for about 35 dollars total (pre-tariff though!)

what the off-board connector looks like

So this thing plugs into another board designed, which I will just gloss over very quickly because it's not the main focus of this article.

This board has banana jacks, providing easy access to power supplies and DMM equipment.

I designed this board to be project-agnostic, and you can tell this from the silkscreen which is very generic and simply calls out the pin numbers. I don't yet have multiple projects where I have needed such a probe interface, but I'm sure the day will come!

Challenges

One challenge I had with my implementation on usage of pins depending on what components were populated on the DUT. For example, if I populated any of these side header pins on my main DUT it made probing very difficult if the corresponding probers were installed on the probe PCB.

My only mess up on this board (really messed up with the PCB under test), is two of the pads are so close together I can't get both the probes down there without having them short together.

There was some slight challenges with soldering alignment. In my previous design I made the probe tip holder so thick it provided good aligment straight towards the test point. However, it was easy enough to just reheat the solder joint and move the probe tip slightly until it's aligned. I'm unsure how to remedy this. One thing would be possibly to stack 2 identical boards with small standoffs to provide the needed alignment, but this seems like overkill and a waste of a PCB.

Conclusion

Status and Results

The board works as expected! I'm really pleased with how this turned out. I also love the look with the green test PCB, the yellow probe board, and the red breakout board.

I think for version 2 of this board I'm designing, it will prove even more useful as I'm anticpating making the layout even tighter and elimating some of the very large test pads I included. With just small (==3mm== diameter) test pads probing them with regular equipment becomes such a pain.

The only small comment is it's slightly annoying having to redo all the standoff screws between swaps. Oh, always something to improve, right?

Looking forwar

This is a project I've designed to be more closely integrated with my software controlled test setup in the future

On the software side I would really like the option to be able to monitor specific voltages of pins. Either through a logic analyzer or an oscilloscope with some connection to my test PC. This would be much more in line with the semiconductor test equipment that I started my career on, where tests oven involved measuring analog voltages.
