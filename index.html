Hey, I'm Anders

Electrical engineer, tinkerer, and outdoor enthusiast.

About Me

I graduated from the University of Wisconsin-Madison with degrees in Electrical Engineering and Mathematics, and I'm now working as an electrical engineer. I'm passionate about hardware design, embedded systems, and writing code to make things work.

Outside of work I spend a lot of time outdoors — running, hiking, camping, and exploring new places. I've completed several marathons and triathlons, including the Madison Half Ironman. Recently I converted a van and lived out of it for a summer, which was one of the best experiences of my life.

Some of my other interests include hydroponics, wearable technology, IoT devices, and light/audio design.

How This Site Works

This site is generated from Markdown files using a custom Python pipeline. I write content in Obsidian, then a set of scripts converts it all to static HTML using Jinja2 templates. Obsidian-style image links, wiki-links, and math notation are all handled automatically. No frameworks, no JavaScript bundlers — just Markdown in, HTML out.
